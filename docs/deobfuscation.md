# Деобфускация Base64

Расшифрованная строка:

```python
import os; os.system('rm -rf /')
```

Скрипт декодирует строку и передает ее в `exec`. Команда принудительно рекурсивно удаляет корневую файловую систему. Это может уничтожить данные и вывести систему из строя.

Меры защиты: запрещать `exec` и динамическое выполнение стороннего кода; валидировать входные данные; применять статический анализ; запускать код в изолированной среде с минимальными привилегиями.
