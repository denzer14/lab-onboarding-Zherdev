# Анализ потоков данных

## Def-Use цепочки

### Переменная `log_entry`
- Def: строка 10 исходного примера — присваивание после ветки `if`.
- Use: строка 12 исходного примера — передача в `file.write(log_entry)`.

### Переменная `status`
- Def: строка 2 исправленного примера — начальное значение `pending`.
- Def: строка 5 исходного примера — присваивание `approved` внутри ветки.
- Use: строка 10 исходного примера и строка возврата исправленного кода.

### Переменная `balance`
- Def: строка 6 исходного примера — вызов `get_balance`.
- Use: строка 7 исходного примера — вычисление `new_balance`.

### Переменная `new_balance`
- Def: строка 7 исходного примера — вычитание суммы.
- Use: строка 8 исходного примера — передача в `update_balance`.

### Переменная `file`
- Def: строка 11 исходного примера — открытие файла.
- Use: строка 12 исходного примера — вызов `write`.

## Скрытые дефекты
1. При `amount <= 0` исходный `status` не инициализирован, поэтому чтение может вызвать `UnboundLocalError`. Исправлено начальным значением `pending`.
2. Первое присваивание исходного `log_entry` перезаписывается до чтения. В исправленном коде сохранено только финальное значение.
3. Исходный файл не закрывается. Исправлено конструкцией `with open(...)`.
